I want to create a React Native + NativeWind (Tailwind) + expo version of the Israeli game "סופר טקטיקו" (Super Tactico). I will deploy this to Vercel, Initially as a web app.

I have a map.txt file (20x20 grid, you can parse my map.txt into a 2D array: S = Sea, L = Land, I = Island) and 2 folders, 1 for each player color: images-blue and images-yellow, each having 20 512x512 pixels PNG assets representing the board pieces. The png files are named like this: <unit>.png I also have there a blank.png file to be used when the piece is unknown or when there are pieces loaded on top of each other (you can write the number of pieces inside the blank). The png pieces are squares, and they have black frame in their edge and rounded corners.

The app will have 3 screens: home the game screen and rules screen. In the Home screen There will be "Super Tactico" game title, "Play Game" button and "Game Rules" button
Put a lot of effort into designing this project. Imagine you are the best designer in the world. Invest in a cool design, especially in the home and game screens. Playing the game, browsing the board situation and having interactions between pieces in the game should feel easy and capturing for the human eye. Every action the players want to perform should feel natural and easy.

Game rules can be found in rules.txt. You need to both put them in the Game Rules screen in a human readable friendly format, and also implement them precisely in the game itself. Do not skip any game rule!
Pay attention to the small details while programming the game mechinics, A M7 ship can carry a Life Raft, which itself can carry soldiers. The state for a cell should be able to hold a nested stack of units.

Initially, I want to create a version of the game that is played from 1 computer only- both players play in the same computer, so you don't need to do all sorts of matching between online players. The yellow player will setup all of the yellow pieces first, then the blue will setup everything, and then the yellow will start turn 1.
